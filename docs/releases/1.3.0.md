## Changes driven by evidence

Independent implementation review added special-file snapshot rejection, bounded capture, raw-log preservation, exact test/action policies, failed-observation-preserving regrading, ancestor-symlink rejection, UTF-8 streaming and POSIX group supervision. Unit regressions cover the counterexamples. Skill guidance now explicitly rejects alternate flags/environment modes under exact-command approval, requires defect-specific RED or an honest gap, and forbids inferring child-agent execution permission from the Delegated style label. A targeted post-clarification repair run used the final group supervisor: it added only the scoped test file, ran the exact command twice, and stopped because only generic file-level failure was visible. It explicitly requested permission for alternate isolation mode rather than running it, left production code unchanged, and did not claim causal RED, implementation success or acceptance. Automatic task-success grading remains **failed/incomplete**; this is one observed safety improvement, not a completed repair or statistical claim. It does not replace the original repeated-run results.

- Roles, budgets and ownership are instructions, not runtime sandboxes or locks. Optional enforced review requires a deliberately configured restricted runtime, including shell/network/child effects; not installed by this release.
- No current-profile activation, new GUI server, production deployment, global style persistence or real multi-agent cancellation integration test.
- Behavioral runner is POSIX-only; structural CI declares Node 22/24 on Ubuntu. Runtime compatibility beyond the tested DSH version is not asserted.
- Audited command subset intentionally rejects some benign shell compositions; semantic review stays separate. The grader cannot parse every shell or prove all test causality.
